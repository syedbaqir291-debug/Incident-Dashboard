Field Guide — Know Your Columns
Understand what fields your log must contain, should contain, and can optionally include
ℹ️ These fields are extracted from a real-world JCI-aligned Master Incident Log. Column names in your file don't need to match exactly — you'll map them in Step 2. Use this guide to ensure your data covers the essentials before uploading.
FIELD TYPE Mandatory Required for any analysis to work Recommended Strongly advised for meaningful insight Optional Enhances detail; not required Auto / Calculated Usually formula-derived; can skip
A
Serial / Incident No. Mandatory
Unique sequential number for each incident record
K
Incident Number Mandatory
System-generated or manually coded incident ID (e.g. IHHN/KRG/IN/2407/001)
M
Incident Date Mandatory
Date the incident occurred (MM-DD-YYYY). Drives Month/Year slicers.
F
Year Mandatory
Calendar year of the incident. Required for year-wise filtering.
O
Department / Ward Mandatory
Where the incident was reported from. Drives department-wise analysis.
R
Incident Category Mandatory
High-level classification (e.g. Medication/Fluid, Fall Event, Equipment)
S
Sub-Category Recommended
Detailed type within the category. Enables sub-category drill-down.
P
Status Mandatory
Current state: Open / In Progress / Closed. Drives status-wise slicers.
Q
Details of Incident Mandatory
Free-text narrative of what happened
V
Clinical / Non-Clinical Recommended
Classify whether the event was patient-clinical or operational/non-clinical
BM
Harm Category Mandatory
Degree of harm: No Harm / Near Miss / Mild / Moderate / Severe / Death. Primary slicer.
BD
Likelihood (1–5) Recommended
Probability score for risk matrix. 1 = Rare, 5 = Almost Certain
BF
Consequence (1–5) Recommended
Severity score. 1 = Negligible, 5 = Catastrophic
BJ
Risk Score (L×C) Auto
Product of Likelihood × Consequence. Can be formula-calculated.
BK
Risk Level Recommended
Low / Moderate / High / Extreme. Mapped from Risk Score.
BL
Sentinel Event (Y/N) Recommended
Flag for serious/sentinel events. Triggers special TAT (45-day) tracking.
BE
Likelihood Description Optional
Text label for the likelihood score (e.g. "Unlikely")
BG
Consequence Description Optional
Text label for the consequence score (e.g. "Major")
BN
Authenticity of Incident Optional
Valid / Invalid / Duplicate. Used to filter out non-genuine incidents.
BB
Corrective Action Recommended
Actions taken to address the immediate incident
BC
Preventive Action Recommended
Systemic actions to prevent recurrence
BV
Total TAT (Days) Recommended
Total turnaround time from incident raised to closure. Benchmarked to 15 days (general) or 45 days (sentinel).
B
TAT Indicator Auto
Auto-flag if TAT exceeded threshold (Sentinel vs General)
W
Forwarding Date Recommended
Date the incident was forwarded for investigation/response
AD
Response Receiving Date Recommended
Date response from responsible department was received
AZ
Response Received (Y/N) Optional
Binary flag confirming whether response was received
BP
Sent for Approval Date Optional
Synopsis/summary submission date for management approval
BQ
Date of Approval Optional
When management formally approved the incident closure
BR
Dissemination Date Optional
Date learning/findings were shared across the organization
D
Campus / Site Name Optional
Facility or campus where the incident occurred. Enables multi-site comparison.
E
Campus Code Optional
Short code for the site (e.g. KRG, SSM). Used in auto-numbering.
G
Patient / Subject Name Optional
Name of the involved patient or subject. Handle per data privacy policy.
H
MR # / Item Code Optional
Medical Record number or equipment item code linked to the incident
I
Age Optional
Patient age at the time of incident. Used for demographic analysis.
J
A/B (Adult/Baby) Optional
Patient classification: Adult or Baby/Paediatric
N
Reporting Staff Optional
Name or ID of the staff member who raised the report
U
Remarks Optional
Additional notes or context added by the quality team
Z
Incident Location Optional
Specific room, ward, or location within the department
BO
Forwarded to HR / S&S Optional
Whether the incident was escalated to HR or Safety & Security
T
Sub-category (Other) Specify Optional
Free-text when sub-category is "Other (please specify)"
